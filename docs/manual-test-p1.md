# P1 手工验收清单

> 逐项测试；失败时报编号（如 F5）+ 现象 + 截图，我读事件日志定位。
> 事件日志：`%APPDATA%\@loomery\shell\sessions\*.jsonl`；渲染诊断日志：同目录 `electron-debug.log`。
> 重启应用 = 关闭所有窗口后 `pnpm --filter @loomery/shell start`。

## 0. 准备（一次性）

| 步骤 | 操作 | 预期 |
|---|---|---|
| 0.1 | 确认所有旧 Loomery 窗口已关闭，启动应用 | 窗口打开，无活动栏，三列布局，状态栏显示 mimo-v2.6-flash |
| 0.2 | 设置页确认：模型清单有 mimo 条目、Base URL 正确、上下文窗口已填 | 显示"使用中" |
| 0.3 | （可选）设置 → 主题切换浅色/深色各一次 | 整体换色，Monaco 同步 |

## A. 左栏 · 会话管理

| # | 步骤 | 预期 |
|---|---|---|
| A1 | 点「＋新建任务」 | 任务列表出现新项，中列/右列清空待输入 |
| A2 | Ctrl+N | 同上 |
| A3 | 发一条消息并等回复完成 | **任务标题从"新会话"变为消息前 24 字** |
| A4 | 悬停任务行 → 点置顶图钉 | 任务跳到列表最前，图标变 ⭐ |
| A5 | 悬停任务行 → 点垃圾桶一次 | 无反应（第一步确认） |
| A6 | 再点一次 | 任务从列表消失；若为当前会话则中列清空 |
| A7 | 搜索框输入标题关键字 | 列表实时过滤 |
| A8 | 项目行点「查看文件」（文件图标） | 左栏切为文件树模式，顶部出现 ← 返回 |
| A9 | 点树中任意 .md 文件 | 右列打开该文件标签 |
| A10 | 点 ← 返回 | 回任务列表；任务列表数据未丢 |
| A11 | 任务列表打开几个任务后点左上 ← / → | 在历史会话间前后切换 |
| A12 | 项目行 ⋯ → 查看该项目文件 | 同 A8 效果 |
| A13 | 左栏底部 ⚙ | 设置浮层打开 |

## B. Composer（输入卡片）

| # | 步骤 | 预期 |
|---|---|---|
| B1 | 点左下预设按钮 | 弹出五项菜单：💡计划/✋变更前确认/🛡自主/⚠️完全访问/🔮解释，当前项带 ✓ |
| B2 | 选「计划模式」→ 查看预设按钮文案 | 显示"计划模式"；再切回「变更前确认」 |
| B3 | 点右下模型名 | 弹菜单显示条目（显示名+供应商标注+✓）；点另一模型可切换 |
| B4 | 点容量圈（空心圆） | 弹面板：总用量+分类条+设置入口；对话后数字应变化 |
| B5 | 输入多行长文本 | 输入框随内容长高（超过约 10 行内部滚动），**卡片宽度不变** |
| B6 | Enter 发送 / Shift+Enter 换行 | Enter 触发发送；Shift+Enter 只换行 |

## C. 对话流（需真实模型）

| # | 步骤 | 预期 |
|---|---|---|
| C1 | 新任务发"你好" | 用户胶囊右侧出现；助手流式回复；结束出现"✓ 已工作 X 秒"与 token 页脚（↑输入 ↓输出） |
| C2 | 观察 mimo 的思考输出 | 有推理时出现"🧠 思考 · 持续 N 秒"折叠块，**块宽度与消息区一致**，展开可见原文；纯思考消息无复制/赞/踩 |
| C3 | 让它输出含列表/表格/代码块的内容（如"用表格列出你的工具"） | markdown 渲染正常，**列表项间距紧凑**，代码块深色 |
| C4 | 点"已工作 X 秒"折叠条 | 展开可见思考/工具行明细；收起只留一行 |
| C5 | 点助手消息里的任意文件路径链接 | 右列新开标签打开该文件 |
| C6 | 对话中点停止 | 进度停止；出现"已停止（userCancelled）"；再可继续发消息 |
| C7 | 长对话直到 Turn 结束 | Turn 页脚显示步数与最终原因；若改动文件则出现"N 个文件已更改 +A −R"汇总卡 |

## D. 工具执行（只读类）

| # | 步骤 | 预期 |
|---|---|---|
| D1 | 发"用工具读一下 package.json" | 过程条内出现"🔍 查阅 · package.json … 完成 · Xms"轻量行 |
| D2 | 点该工具行 | **右列新开标签显示文件内容** |
| D3 | 让它连续读多个文件/列目录 | 多行依次出现，图标区分（🔍 查阅 / 📁 目录）；路径截断不撑破布局 |
| D4 | 点有预览内容的工具行（若无路径参数） | 行内展开预览块 |

## E. 审批与写链路（核心）

| # | 步骤 | 预期 |
|---|---|---|
| E1 | 预设选「变更前确认」，发"把 test.txt 内容改成 hello" | 出现审批卡（⏳ 审批：写操作），卡内 diff 预览 + 接受/拒绝按钮；状态栏出现"挂起审批 1" |
| E2 | 审批卡点「查看完整 diff」 | **右列新开 Diff 标签**（GitCompare 图标，左原始右修改，红绿行） |
| E3 | 按 Ctrl+Enter | 等同点"接受" |
| E4 | （新任务重复 E1，用 Esc） | 等同点"拒绝"；工具卡变"已拒绝"；模型收到拒绝说明 |
| E5 | 接受一次写入 | 文件被改；出现"本轮已修改 N 个文件"checkpoint 横幅与汇总卡 |
| E6 | 状态栏点「↩ 回滚本轮 N 个文件」 | 文件**恢复到修改前内容**（可再让 Agent 读一次验证）；出现回滚 notice |
| E7 | 汇总卡点「查看变更」 | 打开该文件 Diff 标签 |
| E8 | 汇总卡点「撤销」 | 同 E6 回滚（无 checkpoint 时按钮置灰） |
| E9 | 预设切「自主模式」再让它写文件 | 不再弹审批直接写；仍有 checkpoint 与回滚 |
| E10 | 预设切「计划模式」，让它"修改 xx 文件" | 工具卡显示只读限制拦截 notice（🛡 护栏拦截）；文件不被修改 |

## F. 编辑器区

| # | 步骤 | 预期 |
|---|---|---|
| F1 | 标签条点 ＋ | 出现"新标签页"选择页（文件可用；浏览器/终端/审查/辅助对话置灰标注版本） |
| F2 | 新标签页点"文件"→打开 | 左栏切文件树，选文件进编辑器 |
| F3 | 点 ⌄ | 弹出全部标签搜索面板：搜索过滤、点项切换、项尾 ✕ 关闭、底部"关闭全部" |
| F4 | 打开一个 .md | **默认渲染预览**（标题/表格/代码块） |
| F5 | 面包屑点 ⋯ | 菜单：Markdown 组（预览✓/源码）+ 复制绝对/相对路径；切"源码"变为可编辑 |
| F6 | 复制相对路径后粘贴 | 是相对路径（首段为项目名） |
| F7 | 打开一张 png（如 docs/mockups 下） | 图片预览显示，不可编辑 |
| F8 | 打开代码文件改一行不保存 | 标签出现 ● 脏点 |
| F9 | Ctrl+S | 脏点消失；文件实际已保存（可让 Agent 读验证） |
| F10 | 标签点 ⧉ 弹出 | **弹出独立窗口**显示该文件，可编辑可 Ctrl+S |
| F11 | 主窗口右上 — □ ✕ | 最小化/最大化/关闭全部正常 |
| F12 | 顶部面包屑 | 首段为项目名（相对路径），右侧两个按钮（⋯ / 外部打开占位）触达区足够大 |

## G. 会话恢复

| # | 步骤 | 预期 |
|---|---|---|
| G1 | 发一条消息，在回复**流式进行中**直接关窗口 | — |
| G2 | 重启应用点开该任务 | 消息与部分内容还原；该轮标记未完成（页脚/notice 说明） |
| G3 | 完成一个含写入+审批的对话后重启 | 会话完整还原：胶囊/工具卡/审批结果/页脚/汇总卡；出现"已恢复 N 轮"notice |
| G4 | （进阶）审批卡出现、不接受，杀进程重启再开该会话 | 出现"N 个未决审批已失效"提示；可继续新对话 |
